# Сайт маркетолога

Одностраничный сайт специалиста по интернет-рекламе: услуги, этапы работы, кейсы, обратная связь и юридическая информация.

## Структура

- `index.html` — содержимое сайта;
- `style.css` и `reference.css` — оформление и адаптивная версия;
- `script.js` — интерактивные элементы;
- `images/` — изображения и графические материалы.

Сайт собран на HTML, CSS и JavaScript без сторонних фреймворков.
